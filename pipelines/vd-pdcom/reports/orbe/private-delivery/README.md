# Orbe private candidate delivery

`orbe_pilot.persist` is invoked by the existing full/annual acquisition path for the exact reviewed map checksum. It divides the 1295×2159m reference envelope into two queries below the existing 2km-per-axis limit. Each snapshot retains official URL, response hash, count, current commune, geometry and time evidence.

Overlapping EGRIDs must have identical geometry and attributes. The merged current intersection keyset and geometry must match the reviewed official snapshot before candidate insertion; any change fails for review. Existing candidate geometry/membership also cannot be overwritten silently. A deterministic snapshot link supplies FK-backed provenance for every pair.

The candidate uses the outer edge of the cartographic band for inclusive private review. Its evidence retains the inner/outer scenarios and 34 outer-only EGRIDs. Intersections with the band or within 10m of it require boundary review. This is not a surveyed error bound. Preserve 28 DDP superficie objects distinctly from land and do not count the band as an extra sector. Other categories remain pending.

The source's unsigned2021 PDF versus municipal2022 approval listing, four footprint-centroid outliers and other shape differences remain explicit. No public release or complete-commune status is granted. Use receipt.json for verified live outcome; future changed official geometry requires a new review rather than silent replay.
