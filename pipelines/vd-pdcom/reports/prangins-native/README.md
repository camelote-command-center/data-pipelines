# Prangins historical native source features

The pinned batch preserves original line centrelines and exact common endpoints of viewpoint cone rays. It uses the same independently reviewed 2013 synthesis transform as prior source collections. These source symbols are indicative historical objectives, not current infrastructure certification, cadastral areas or surveyed coordinates. No buffers or parcel candidates are produced.

The existing private review route assigns each feature to all communes with positive line overlap or covering the point. Multi-commune attribution is retained; document commune membership is separate. Source geometry is not clipped to Prangins.

The exact source SHA, source path IDs/styles, policy/legend evidence, PDF and LV95 geometry, and affine transform are in batch.json. Source semantic allowlists retain omitted/ambiguous cases. Multiple source paths may represent parts of one route; collection/path counts are not route counts. Currentness, map precision and commune completion remain unresolved.
